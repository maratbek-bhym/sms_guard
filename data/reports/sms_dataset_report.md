# Отчёт по SMS-данным

**Дата генерации:** 2026-11-13 · **random_state:** 42 · **Скрипты:** `ml/data/generate_sms.py`, `ml/data/sms_templates.py`, `ml/data/build_datasets.py`

## Происхождение
- **Реальные открытые данные: НЕ использованы.** В среде выполнения не было доступа к интернету, UCI SMS Spam Collection не загружен. Скрипт загрузки/чтения — `ml/data/download_open.py`, `ml/data/load_sms.py` (не запускались).
- **Синтетические данные: 100 %.** Сгенерированы из шаблонов с вариативными блоками `{a|b|c}` и подстановками. Все телефоны, карты, имена и организации вымышлены; URL — только `.example/.test/.invalid` и адреса TEST-NET (проверено автоматически, нарушений: 0).
- Это **не реальные SMS пользователей**. Казахские шаблоны написаны автором данных, не переводом; носителем языка не проверены.

## Объём и баланс
Бинарных сообщений: ru 1250, kk 850, en 1050 (итого 3150, 50/50 по каждому языку) + 180 сообщений класса `suspicious` (по 60 на язык, **исключены из бинарного обучения**, используются только для анализа).

## Разбиение
`StratifiedGroupKFold(7)`, группа = шаблон-семейство, стратификация по язык×класс. Семейств: {'train': 100, 'val': 21, 'test': 20, 'eval_only': 9}. Индексы — `data/processed/sms/sms_split.json`.

## Ограничения (важно)
1. **Мало независимых семейств:** по 19 безопасных и ~28 мошеннических шаблонов на язык. Групповое разбиение оставляет в test по 2–3 безопасных семейства на язык, поэтому отдельные категории (например, коды подтверждения, доставка) целиком отсутствуют в train. Оценка высоко-дисперсная.
2. Длина сообщений коррелирует с классом (мошеннические длиннее): ru 118 vs 69 символов в среднем.
3. Внутри семейства лексика сильно перекрывается (639 почти-дубликатов): объём 3150 ≠ 3150 независимых примеров.
4. Часть формулировок грамматически неидеальна (следствие комбинаторных вариантов).
5. Данные не подтверждают качество на реальных SMS и не позволяют заявлять поддержку ru/kk.
