# Отчёт по URL-данным

**Скрипты:** `ml/data/url_gen.py`, `ml/data/generate_urls.py`, `ml/data/build_datasets.py` · random_state 42

## Происхождение
- **Реальные открытые данные (PhiUSIIL, Malicious URLs): НЕ использованы** (нет доступа к сети). Скрипт загрузки: `ml/data/download_open.py` (не запускался).
- **Синтетика: 12 000 URL** (6000 безопасных / 6000 фишинговых), 27 типов генерации (`kind`). Только `.example/.test/.invalid` и TEST-NET/`2001:db8::`. Нарушений правил: 0. Сеть и DNS не использовались.
- Один и тот же набор TLD и схем в обоих классах, чтобы класс не определялся зоной. Следствие: признак `suspicious_tld` на этих данных всегда 0 и **не обучен**.
- Для безопасных URL добавлены «сложные» случаи (логин-страницы легитимных сайтов, IDN, сокращатели, порты, IP во внутренних адресах); для фишинга — URL без ключевых слов (`phish_no_kw`, `phish_plain_like`: внешне обычные адреса, **принципиально неотличимые** от безопасных).

## Ограничения
Адреса синтетические: модель выучила структуру генератора, а не реальный фишинг. Реальные домены (.com, .kz) в обучении отсутствуют; на реальных безопасных URL возможны ложные срабатывания (см. проверку на 20 URL в `url_model_meta.json`).
